# Images

This folder contains images used to document the STM32 CAN telemetry system.

The images show the system architecture, telemetry data flow, hardware prototypes, wiring, and final two-node integration setup.

## Contents

| File / Image Type | Description |
|---|---|
| `system_architecture.*` | High-level architecture diagram of the two-node telemetry system. |
| `telemetry_data_flow.*` | Data flow diagram from IMU acquisition to MATLAB analysis. |
| `vehicle_dynamics_node.*` | Image of the Vehicle Dynamics Node hardware. |
| `logger_node.*` | Image of the Logger Node hardware. |
| `full_prototype.*` | Image of the complete two-node breadboard prototype. |

## Notes

These images are used for project documentation and visual evidence of the prototype implementation.

The hardware shown is a controlled bench prototype built using STM32 NUCLEO-F446RE boards, external modules, breadboards, and jumper wiring. It is not intended to represent a vehicle-qualified hardware installation.
