# Results and Test Evidence

This folder contains sample outputs and evidence from the final STM32 CAN telemetry system tests.

The files in this folder demonstrate that the system successfully acquired IMU data, transmitted it over CAN, timestamped and logged it to a microSD card, and processed the logged data in MATLAB.

## Contents

| Folder / File | Description |
|---|---|
| `LOG.CSV` | Sample telemetry log generated by the Logger Node. |
| `replay_video/` | Video comparison between physical prototype movement and the MATLAB offline orientation replay. |
| `matlab_plots/` | Plots generated from the logged telemetry data. |
| `uart_outputs/` | UART screenshots from subsystem and integration testing. |

## Sample CSV Log

`sample_LOG.CSV` contains timestamped IMU telemetry written by the Logger Node.

Each row contains:

```csv
timestamp,time_ms,accel_x,accel_y,accel_z,gyro_x,gyro_y,gyro_z,status
```

The CSV file can be opened in Excel or imported into MATLAB for analysis.

## Replay Video

The replay video compares the physical movement of the prototype board with the offline MATLAB 3D orientation replay generated from the logged telemetry data.

This provides qualitative validation of the full telemetry chain:

```text
physical board movement
→ MPU-6050 IMU measurement
→ CAN transmission
→ Logger Node reception
→ RTC timestamping
→ microSD CSV logging
→ MATLAB post-processing
→ offline 3D orientation replay
```

## Long-Duration Logging Test

A long-duration bench test was performed to check sustained CAN reception and SD card logging reliability.

The optimised Logger Node firmware produced approximately 30,000 CSV rows in 50 minutes, corresponding to an average sustained logging rate of approximately 10 samples/s.

This confirmed that keeping `LOG.CSV` open during acquisition and periodically calling `f_sync()` significantly improved logging performance compared with opening and closing the file for every row.

## Notes

The results were collected from a controlled bench prototype. The replay and plots are intended for qualitative validation rather than precision-calibrated vehicle testing.
