# MATLAB Post-Processing

This folder contains the MATLAB scripts used to analyse telemetry data logged by the STM32 CAN telemetry system.

A sample `LOG.CSV` file is included in this folder so that the scripts can be run directly without changing the file path.

## Files

| File | Description |
|---|---|
| `LOG.CSV` | Sample telemetry log generated by the Logger Node. |
| `Basic_PLot.m` | Imports `LOG.CSV`, converts raw IMU data into physical units, and plots accelerometer and gyroscope data. |
| `Offline_BoardDisplay.m` | Imports `LOG.CSV`, estimates roll and pitch, and replays the estimated board orientation using a 3D MATLAB dashboard. |

## How to Run

Open MATLAB and set the current folder to this `matlab/` directory.

Then run either:

```matlab
Basic_PLot
```

or:

```matlab
Offline_BoardDisplay
```

The scripts expect `LOG.CSV` to be in the same folder.

## CSV Input Format

The scripts expect the telemetry CSV file to contain the following columns:

```csv
timestamp,time_ms,accel_x,accel_y,accel_z,gyro_x,gyro_y,gyro_z,status
```

The included sample `LOG.CSV` follows this format.

## Unit Conversion

The logged IMU values are stored as raw signed integer values from the MPU-6050.

The accelerometer was configured for a ±8 g range, so raw accelerometer values are converted using:

```matlab
accel_g = raw_accel / 4096;
```

The gyroscope was configured for a ±250 degrees per second range, so raw gyroscope values are converted using:

```matlab
gyro_dps = raw_gyro / 131;
```

## Basic Plot Script

`Basic_PLot.m` creates two MATLAB figures:

1. Accelerometer data converted to `g`
2. Gyroscope data converted to `deg/s`

This script is useful for quickly checking that the logged telemetry data was imported correctly and that the IMU values changed during motion.

## Offline Board Display Script

`Offline_BoardDisplay.m` creates an offline replay dashboard.

The dashboard includes:

- A 3D board model
- Estimated roll and pitch plot
- Moving time marker
- Time slider
- Play and pause controls

Roll and pitch are estimated from the accelerometer gravity vector:

```matlab
roll = atan2d(ay, az);
pitch = atan2d(-ax, sqrt(ay.^2 + az.^2));
```

Yaw is set to zero because the MPU-6050 does not provide an absolute heading reference. A magnetometer would be required for reliable yaw estimation.

## Notes

The MATLAB replay is intended as a qualitative visualisation tool rather than a precision-calibrated attitude estimation system.

The included `LOG.CSV` file is a sample dataset so that the analysis scripts can be tested immediately after cloning or downloading the repository.
